# SiPhone

**Мобильная SIP-звонилка на Kotlin + Jetpack Compose.**

> ⚠️ **Статус проекта:** учебный шаблон, создан как пример того, как устроен SIP-звонок
> в Android-приложении на Linphone SDK. Проект **активно развиваться не будет**:
> он не претендует на роль полноценного телефона и служит стартовой точкой
> для изучения технологии.

> 📵 **Важно:** приложение умеет **только звонить** (исходящие звонки).
> **Принимать входящие звонки оно не умеет** — в нём нет постоянной
> регистрации, экрана входящего вызова и фонового сервиса.

---

## Возможности

- Цифровая клавиатура и исходящий SIP-звонок
- Реальный сервер и **mock-режим**: тестовый звонок без SIP-сервера
- Сигнал **«гудки»** при дозвоне
- Светлая / тёмная тема
- Экран «О приложении» (название, версия, автор, лицензии)

## Чего здесь нет (и не будет)

- ❌ Приём входящих звонков
- ❌ Работа при свёрнутом приложении / в фоне (Foreground Service)
- ❌ Push-уведомления о звонках
- ❌ Видеозвонки, чаты и контакты

Если вы хотите **полноценный** SIP-клиент с приёмом звонков —
возьмите этот проект как основу и добавьте постоянную регистрацию,
обработку `IncomingReceived` и уведомления самостоятельно.

## Как работает звонок

1. Пользователь набирает номер и нажимает «Позвонить».
2. Приложение запрашивает разрешение на микрофон (только для реального звонка).
3. `SipManager` (фасад) по настройкам выбирает реализацию; для реального звонка
   `LinphoneSipController` поднимает ядро Linphone и регистрирует аккаунт на сервере.
4. После успешной регистрации отправляется `INVITE`.
5. Пока идёт дозвон, звучит сигнал «гудки».
6. После соединения включается аудио (`MODE_IN_COMMUNICATION`), доступны
   mute и громкая связь.
7. При завершении звонка ресурсы ядра освобождаются, аудио сбрасывается.

В **mock-режиме** (Настройки → Сервер → «Mock-сервер») Linphone и сеть
не используются: `MockSipController` эмулирует жизненный цикл вызова — от гудков
до автоматического завершения. Удобно для быстрой проверки интерфейса.

## Технологии

- **Kotlin** + Coroutines
- **Jetpack Compose** + Material Design 3
- **Linphone SDK** (`org.linphone:linphone-sdk-android`)
- Android Gradle Plugin 9.3.2, minSdk 26, targetSdk 36

## Структура проекта

```
app/src/main/java/ru/merrcurys/siphone/
├── MainActivity.kt                    # экран-контейнер: разрешения, навигация, переходы
├── sip/
│   ├── SipCallController.kt           # интерфейс контроллера звонков
│   ├── SipManager.kt                  # фасад: выбор реализации по настройкам
│   ├── LinphoneSipController.kt       # реальные звонки: ядро Linphone, регистрация, аудио
│   ├── RingbackTone.kt                # генерация WAV «гудков» прямо на устройстве
│   └── mock/
│       └── MockSipController.kt       # эмуляция звонка без реального SIP-сервера
├── data/repositories/
│   └── SettingsRepository.kt          # SharedPreferences: сервер, SIP-креды, тема, mock
└── ui/
    ├── theme/                         # Material 3: цвета, типографика, appTheme
    ├── screens/
    │   ├── DialScreen.kt              # цифровая клавиатура и кнопка вызова
    │   └── SettingsScreen.kt          # настройки сервера, темы, «О приложении»
    └── components/
        └── CallScreen.kt              # экран активного (исходящего) звонка
```

## Установка и запуск

1. Клонируйте репозиторий.
2. Откройте проект в Android Studio.
3. Дождитесь синхронизации Gradle.
4. Запустите на эмуляторе или устройстве (Android 8.0 / API 26+).

> APK собирается обычной командой: `gradlew assembleRelease`
> (R8 + сжатие ресурсов включены для release-сборки).

## Быстрый старт

| Хочу…                                        | Действие |
|----------------------------------------------|----------|
| Протестировать звонок без сервера            | Настройки → Сервер → включите **Mock-сервер**, наберите любой номер |
| Позвонить через реальный SIP-сервер          | Настройки → укажите **IP сервера**, **SIP ID**, **пароль** → наберите номер |
| Сменить тему                                 | Настройки → **Тема оформления** |
